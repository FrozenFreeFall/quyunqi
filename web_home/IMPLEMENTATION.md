# 趣伴云起网站实现记录

目标：用独立静态网站介绍现有小程序，展示用户提供的真实小程序码，并支持 GitHub Pages 托管。

采用原生 HTML、CSS、JavaScript；无需构建和第三方 CDN。源码和素材均位于 web_home，只有 GitHub 要求的工作流位于仓库根目录 .github/workflows。

页面采用暖白、森林绿、日光黄，复用小程序山水插画。内容依次为首页介绍、活动类型、功能演示、使用步骤、常见问题和扫码入口。示意活动和人数明确标注为演示，不声称真实用户量。费用描述与源码一致，为线下收款、人工核账。

- [x] 创建响应式页面，素材使用相对路径，支持仓库子路径。
- [x] 完成可切换的活动示意、二维码放大弹窗、图片下载链接、手机导航和 FAQ。
- [x] 提供仅上传 web_home 的 Pages 工作流、部署及素材替换说明。
- [x] 本地 HTTP 和浏览器验证桌面/手机布局、交互、资源加载，执行项目现有检查。

二维码使用用户原图，无重新编码或图像压缩；方形展示仅使用 CSS 定位，下载保留原始完整图片，桌面弹窗显示完整横幅、手机弹窗放大左侧小程序码。当前 remote 为 Gitee，无指定 GitHub 仓库，交付可部署源码及配置，不推送或发布。

用户调整：图标采用山野风，以本地 SVG 绘制青山、日出、溪流，统一页头、页尾及 favicon。未修改小程序本身的图标。

验证记录：

- `node --check web_home/app.js` 通过；`node tools/check.js` 通过：138 个 JavaScript 文件、27 个 JSON 文件和 11 个小程序页面。
- `node --test 'tests/*.test.js'`：1083 项全部通过。
- 本地 `/web_home/` 和原始二维码 URL 返回 HTTP 200；素材相对路径检查通过，原码 SHA-256 与用户附件完全一致。
- 浏览器检查了 320、390、768、1280、1440 像素宽度；无横向溢出。完成场景切换、点击/方向键切换功能标签、手机菜单打开及收起、FAQ 展开、二维码弹窗及 Esc 关闭检查；无浏览器错误或警告。
- 独立审阅提出正文对比度偏低，已加深说明文字，典型正文对比度提升至 4.61–5.22:1。窄屏隐藏可能被二维码遮挡的示意徽章。
- 下载链接使用浏览器原生 `download` 属性，原图 URL/响应正常；内置浏览器未返回自动化下载事件，未确认系统保存结果。微信扫码、相册识别及正式 Pages 发布需要对应真实环境确认。
